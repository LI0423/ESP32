# DeskPal pet-v2 美术制作规范

## 当前风格基线

现有角色是一颗带叶子的橙色小橘子：

- 128×128 透明底索引像素图
- 深棕厚描边，圆润短胖轮廓
- 暖橙身体色 + 有序抖动色阶
- 黄绿色叶片，少量高光
- 表情只改动少量像素，不改变身体轮廓
- 无抗锯齿、无渐变、无写实渲染

原始参考：`assets/deskpal/deskpal-char-focus-128.png`。

## 技术交付要求

每个可运行精灵必须满足：

| 项目 | 要求 |
| --- | --- |
| 画布 | 128×128 |
| 格式 | 索引 PNG，P 模式 |
| 透明 | index 0 透明，不能有黑底 |
| 颜色 | 最多 32 色，优先共用现有调色板 |
| 像素 | 硬边像素，无抗锯齿、无半透明边缘 |
| 位置 | 角色中心 x=64，底部对齐 y=125 |
| 安全区 | 内容尽量保持在 x=6..122、y=5..125 |
| 描边 | 1–2 px 深棕，主色 `#311705` |
| 输出 | 独立 PNG，不要直接把文字或 UI 烘进图里 |

现有调色板可直接使用 `assets/deskpal/deskpal-shared-palette.png`。主要颜色：

- 高光：`#F5D07A`
- 亮橙：`#EE873D`
- 主橙：`#DE6B26`
- 中橙：`#DA601D`
- 暗橙：`#A33D13`
- 深棕：`#311705`
- 叶片：`#C4A044` / `#37300C`

## 成长阶段

四个阶段必须保持同一角色身份，不能只换颜色：

1. **Baby**：最小、最圆、叶子最小，幼年比例
2. **Child**：略高，轮廓开始从正圆变成椭圆
3. **Teen**：明显拉高，略呈梨形，叶片更展开
4. **Adult**：最大、最宽，成熟但仍保留可爱圆润感

当前概念稿采用“同一圆橘轮廓逐步放大”的保守方案；如果后续要更强成长感，可在 Teen/Adult 增加很小的手脚或双叶，但不要变成人形。

## 照护动作

第一版需要 4 个动作精灵：

- `feed`：开心进食，出现小食物
- `medicine`：手持小药瓶，表情平静
- `play`：跳跃或伸手，出现小球
- `clean`：开心或闭眼，出现泡泡/闪光

动作道具不能超出安全区。蓝色泡泡/药瓶若无法进入现有 32 色板，可改成奶油黄/浅黄，或为动作组单独增加第三套 32 色调色板。

## 建议素材包规模

| 素材包 | 数量 | 索引数据量 |
| --- | ---: | ---: |
| 最小可上线包 | 4 阶段 + 4 动作 | 8 × 16KB = 128KB |
| 完整表情包 | 再加每阶段 hungry/sick/sleep | 约 384KB |
| 两帧动画包 | 每个动作 2 帧 | 再增加约 64–128KB |

当前 OTA 固件剩余约 26%，不建议把完整素材包直接塞进 app。优先使用已有 6MB `assets` 分区，app 只保留加载/选择逻辑。

## 文件与生成流程

概念稿与处理脚本：

- `grok-growth-stages.jpg`：Grok 四阶段原始概念图
- `grok-action-sheet.jpg`：Grok 四动作原始概念图
- `deskpal-pet-*-grok-128.png`：已拆分为 128×128、32 色、透明底的索引 PNG
- `tools/gen_pet_v2_concepts.py`：无外部额度时的程序化像素绘制版本
- `tools/process_grok_pet_sheet.py`：四阶段拆图、缩放、调色板量化
- `tools/process_grok_action_sheet.py`：2×2 动作拆图、暖色重映射、调色板量化

Grok 版四阶段与四动作已接入固件索引精灵生成器，并嵌入当前 app。程序化版保留为本地备选，未编译进固件。原始概念图、处理脚本和制作规范均保留在 `assets/deskpal/pet-v2/`。
